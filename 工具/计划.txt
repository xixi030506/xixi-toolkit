二、【核心文件通俗科普：它们各自是什么？怎么配合工作的？】

1. 什么是 .html / .py / .json / .bat / .pyc？
   - 【.html（前端网页界面）】：就像「店面装修和收银台服务员」。它负责所有看得见的漂亮按钮、滑块、A4 预览画布。但因为浏览器安全限制，纯 HTML 没法自己偷偷在硬盘建文件夹或调起 Windows 资源管理器高亮文件。
   - 【.py（Python 后台脚本）】：就像「拥有电脑最高权限的后厨大厨」。它可以自由读写本地硬盘、创建子文件夹、弹出原生的 Windows 文件夹选择框、调用 git 更新版本。
   - 【xixi_toolkit_launcher.py 与 stamp_studio_backend.py 的关系】：
     · `xixi_toolkit_launcher.py` 是「商场总管」，只管大厅里的分类、拖拽、Git 更新和切换窗口；
     · `stamp_studio_backend.py` 是「西西盖章局这家店自己的后厨」，只管盖章局的 5 个子文件夹和历史记录。两者解耦后，以后你有 10 个插件，总管代码也不会臃肿！
   - 【__pycache__ / stamp_studio_backend.cpython-311.pyc】：
     · 这是 Python 运行 `stamp_studio_backend.py` 时自动生成的「加速缓存文件」（311 代表 Python 3.11）。完全不用管它，删了下次运行也会自动再生成，且已在 `.gitignore` 中被自动屏蔽，不会上传到 Git。
   - 【.json（数据记忆本）】：就像「结构化的记事本」，专门用来存配置和数据：
     · `prefs_config.json`（在 `历史缓存/` 下）：记住你选的默认保存文件夹、方案①②③参数、默认后缀，下次打开原样恢复。
     · `history.json`（在 `历史缓存/` 下）：记住你每一次保存的文件名、路径、时间、备份文件名，支撑左侧「📜 历史记录」的撤回与恢复。
     · `自定义样式/*.json`：记住你导出的水印样式参数。
   - 【点我启动.bat】：Windows 批处理点火开关。双击它会先检查电脑有没有装 `pywebview`，没装就自动连清华镜像源装好，然后用 `pythonw`（无黑框模式）打开总控启动器。

三、【Git 一键上传、别人一键同步最新版、遇到 Bug 一键回退全流程】

1. 为什么更新或回退版本【绝对不会】删掉别人存的自定义图片、样式和历史记录？
   - 因为我们在根目录的 `.gitignore` 里明确写死了：
     `**/自定义样式/*`、`**/自定义图片/*`、`**/历史缓存/*`、`**/默认导出/*`
   - Git 会把这些文件夹里的内容视为「用户私有未跟踪文件 (Untracked)」，无论是点「⬇️ 一键同步最新版」还是「⏪ 回退到此版」，Git 只会替换 `.html` 和 `.py` 代码文件，绝不会碰这四个文件夹里的任何文件！

2. 你作为开发者怎么上传更新？
   - 方法 A（图形界面）：打开工具包 -> 点击右上角「☁️ 更新与回退」 -> 切到「🚀 开发者一键上传」 -> 输入一句说明点推送。
   - 方法 B（双击脚本）：直接双击根目录下的 `开发者一键上传更新.bat`，按回车即可一键完成 `git add` + `git commit` + `git push`。

3. 别人怎么更新或遇到 Bug 怎么回退？
   - 在启动器右上角点「☁️ 更新与回退」：
     · 点「⬇️ 一键同步最新版」即可实时拉取你的最新代码，并自动安装新增的依赖库；
     · 下方列表会列出最近 25 个历史版本，万一最新版有 Bug，点任意旧版本右侧的「⏪ 回退到此版」即可 1 秒退回旧版！
   - 万一连界面都打不开，双击根目录下的 `一键更新与回退版本.bat` 也能在菜单里按数字 1 更新、按数字 2 回退！

四、【以后新增第 2、第 3、第 N 个插件的标准三步法（以本次为模板）】

步骤 1：复制模板文件夹
  - 将根目录下的 `_新插件标准模板_复制改名` 复制一份，改名为你的新插件名（注意去掉开头的 `_`，比如改名为 `西西图片工坊` 或 `西西PDF合并`）。
  - 只要文件夹名不以 `_` 或 `.` 开头，总控启动器下次打开时就会【自动扫描发现它】并生成插件卡片！

步骤 2：写该插件需要的库 (`requirements.txt`)
  - 打开新插件文件夹里的 `requirements.txt`，把该插件用到的 Python 库按行写进去（例如 `pillow>=10.0.0`、`pymupdf>=1.23.0`）。
  - 用户点击打开该插件时，启动器会自动检索这个 `requirements.txt`，如果发现对方电脑没装，会自动调清华源静默装好！

步骤 3：写前后端代码
  - 纯网页工具：直接改文件夹里的 `index.html` 即可（左上角已内置「⬅️ 返回工具包」按钮，即使没写启动器也会自动注入）。
  - 需要读写本地硬盘的工具：在文件夹里保留 `xxx_backend.py`（类名以 `Backend` 结尾），启动器打开该插件时会自动加载它！
